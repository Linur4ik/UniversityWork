# DICOM Steganography Tool

DICOM Steganography Tool — это графическое приложение на Python с использованием PyQt5, предназначенное для сокрытия и извлечения персональных данных внутри медицинских изображений в формате DICOM. Оно поддерживает работу с различными типами шторок (shutter), шифрование метаданных с использованием AES-128 и визуализацию DICOM-изображений до и после обработки.

## Особенности

* Встраивание пользовательских DICOM-тегов в изображение
* Поддержка шифрования метаданных (AES-128)
* Поддержка RECTANGULAR, CIRCULAR и POLYGONAL шторок
* Интерактивный выбор метаданных для встраивания
* Визуализация оригинального и обработанного изображения
* Извлечение и сохранение скрытых данных обратно в DICOM-файл

## Запуск приложения

```bash
python main.py
```

## Использование

### Встраивание данных:

1. Откройте вкладку "Embed Data"
2. Выберите DICOM-файл
3. Настройте шторку (если доступно)
4. Отметьте метаданные для встраивания
5. Включите шифрование (опционально)
6. Нажмите "Embed Data and Save"

### Извлечение данных:

1. Перейдите во вкладку "Extract Data"
2. Выберите модифицированный DICOM-файл
3. Укажите ключ расшифровки, если данные были зашифрованы
4. Нажмите "Extract Metadata"
5. (Опционально) Сохраните DICOM с восстановленными тегами
